One-time setup for the Start button

The button needs permission to start your bot on GitHub. Until then, the automatic runs still happen.
  1. On GitHub: your picture → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → RoboMoney. Permissions: Actions: Read and write. Generate and copy it.
  3. On Vercel: project robomoney-replay → Settings → Environment Variables. Name GITHUB_TOKEN, paste the token, save.
  4. Tell Claude "done" so it can refresh the site.
