Set up sending

✅ This device can send messages to the chat.

To send from this page, it needs a key from your GitHub account. You only do this once per device.

  1. Open GitHub → New fine-grained token.
  2. Name: AI Chat. Expiration: 90 days.
  3. Repository access: Only select repositories → RoboMoney.
  4. Permissions → Repository permissions → Contents → Read and write. Nothing else.
  5. Click Generate token, copy it, and paste it below.

The key stays only on this device. Never paste it into a chat, not even with Claude. You can cancel it anytime on GitHub.
